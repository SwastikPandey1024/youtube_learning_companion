> [!abstract] Theorem: **Orthogonality vs Linear Independence** ([13:00](https://youtube.com/watch?v=DrCeIbpfuzE&t=780s))
> **Statement:** Orthogonal vectors are always linearly independent if non-zero, but linearly independent vectors need not be orthogonal.
> 
> **Conclusion:** Orthogonal vectors are always linearly independent if non-zero, but linearly independent vectors need not be orthogonal.

> [!abstract] Theorem: **Diagonalizability of Square Matrices** ([15:20](https://youtube.com/watch?v=DrCeIbpfuzE&t=920s))
> **Statement:** A matrix is diagonalizable if and only if it possesses n linearly independent eigenvectors.
> 
> **Conclusion:** A matrix is diagonalizable if and only if it possesses n linearly independent eigenvectors.
